# SprintOps-Tracker — Frontend

React + Vite single-page client for the SprintOps-Tracker V0.1 API.

## Commands

| Command | Purpose |
|---|---|
| `npm run dev` | Dev server |
| `npm run build` | Production build |
| `npm run lint` | ESLint |
| `npm test` | Vitest |

Copy `.env.example` to `.env` and set `VITE_API_BASE_URL` to the API origin
(the client appends `/api/v1`).
